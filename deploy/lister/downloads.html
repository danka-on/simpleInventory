One-time setup on each computer

  1. Create an empty folder named Sweet Shelves Lister (for example in Documents) and choose it above, or choose the folder you already loaded.
  2. Click Update & reload. New installation? Open chrome://extensions, enable Developer mode, choose Load unpacked and select that folder. Pin the extension and click its icon on an eBay or Seller Central tab to open the panel.
  3. The panel uses this browser's Sweet Shelves sign-in. If it says sign in, open the review page once and go back to the panel.
  4. Bookmark this page. Next time, click Update & reload, then refresh your eBay and Seller Central tabs.

Windows PCs: automatic updates over Tailscale

Optional. Runs every five minutes while you are signed in and applies updates when Chrome and Edge are fully closed, the same way AmazingScout updates. Requires Tailscale connected on that PC.

Enter the folder already loaded with Load unpacked to keep its extension ID and settings. Leave it blank for a new installation.





Later, run %LOCALAPPDATA%\SweetShelvesLister\Update Sweet Shelves Lister.cmd for an immediate update, or rerun the command with -RemoveAutoUpdate to stop automatic checks.
