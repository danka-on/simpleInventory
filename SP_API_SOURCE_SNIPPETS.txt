================================================================================
2. CLIENT._REQUEST() - THE CORE METHOD
================================================================================
File: sp_api/base/client.py

def _request(self, path: str, *, data=None, params=None, headers=None,
             add_marketplace=True, res_no_data=False, bulk=False,
             wrap_list=False) -> ApiResponse:
    
    # Extract HTTP method
    self.method = params.pop("method", data.pop("method", "GET"))
    
    # Add marketplace ID
    if add_marketplace:
        self._add_marketplaces(...)
    
    # THE ACTUAL HTTP REQUEST using requests library:
    res = request(
        self.method,
        self.endpoint + self._check_version(path),
        params=params,
        data=json.dumps(data) if data and self.method in ("POST", "PUT", "PATCH") else None,
        headers=headers or self.headers,
        timeout=self.timeout,
        proxies=self.proxies,
        verify=self.verify,
    )
    return self._check_response(res, res_no_data, bulk, wrap_list)

================================================================================
5. REQUEST FLOW
================================================================================

1. User calls: shipping.get_account()

2. Shipping.get_account() executes:
   return self._request(kwargs.pop("path"), params=kwargs)

3. Client._request() method:
   a. Extracts HTTP method: "GET" (default)
   b. Adds marketplace ID to params
   c. Calls requests.request() with:
      - URL: https://sellingpartnerapi-na.amazon.com/shipping/v1/account
      - Headers: includes x-amz-access-token, x-amz-date
      - Method: GET
      - Params: marketplace info

4. requests library makes actual HTTP request

5. Response parsed and returned as ApiResponse object


================================================================================
6. KEY FINDINGS
================================================================================

1. Base class method: Client._request() inherited by Shipping
2. HTTP library: requests (standard Python)
3. Auth mechanism: OAuth 2.0 token in x-amz-access-token header
4. Custom requests: Call shipping._request(path, data=..., params=...)
5. Endpoint pattern: /shipping/v1/{operation}
6. Base URL: depends on marketplace initialization
7. Token refresh: automatic via Client._auth.get_auth()
8. Marketplace ID: automatically added by Client._add_marketplaces()
9. Error handling: _check_response() raises exceptions for HTTP errors


================================================================================
7. MAKING CUSTOM REQUESTS
================================================================================

from sp_api.api.shipping import Shipping
from sp_api.base import Marketplaces

shipping = Shipping(
    marketplace=Marketplaces.US,
    refresh_token="your_token"
)

# Call _request() directly for custom endpoints:
response = shipping._request(
    "/shipping/v1/account",
    params={"method": "GET"}
)

# POST example:
response = shipping._request(
    "/shipping/v1/shipments",
    data={"clientReferenceId": "test", ...},
    params={"method": "POST"}
)

Benefits:
- Automatic OAuth token handling
- Automatic marketplace ID addition
- Automatic error handling
- Automatic response parsing
